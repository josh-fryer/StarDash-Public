# Star Dash: Infinity
An endless runner action game for mobile. Swipe to dodge asteroids and tap to fire lasers.

For fun and to learn how to integrate Ads and deploy to mobile devices, I created this simple game project.
It is a game where you swipe to avoid oncoming obstacles and tap to shoot targets to gain points. Made with the Unity Game Engine with code in C#. 
Ads are delivered by Googles Ad Mob using their SDK. It was deployed on Android Play Store and live from 2022-2024.
